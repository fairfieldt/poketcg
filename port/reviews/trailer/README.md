The current 1:12.58 teaser uses fresh 480×360 Expansion Pak captures, delivered
at 1440×1080 and 60 fps. Native gameplay targets 30 fps; recorded frames are
held or dropped without motion interpolation. The previous version also used
480×360, rather than 320×240.

The updated cut removes the cast's extra opaque preview shadows, adds Ronald's
original challenge before his battle, and holds at the legendary card while it
glows. The original legendary-card sound begins with the glow. The recording
checks reject truncated captures and long frame gaps in this edit.

The user chose local capture while the usual recording host was offline. This
video shows native post-VI output without a CRT shader. The [previous CRT
teaser](v3/poketcg64-trailer.mp4) remains available. Both current MP4 filenames
point to the same clean version for existing links.
