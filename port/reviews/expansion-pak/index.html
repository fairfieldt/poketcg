Validation

62 post-VI captures pass exact PNG-to-callback RGB checks. Every stage waits for its matching native framebuffer header, six later valid callbacks and six stable frames.

Both complete native suites pass: 34 maps, 42 captures, story, opening, SRAM and an actual engine duel per RAM mode. The 4 MiB and 8 MiB scene comparisons use the same diagnostic ROM.

All four lead meshes and aliases remain unchanged; the cast stays within 906 triangles and six batches per actor.

Eight-actor room render medians: 320×240 110.1 ms; 480×360 110.1 ms. These are ares emulated timer measurements, not physical-console FPS.

Combined validation · Build and capture notes

Raw 640×240 VI captures are shown at 4:3; comparison sheets duplicate rows exactly. Raw 640×480 captures remain unchanged. Head crops use the same rectangle on a 640×480 display canvas, then 2× nearest scaling. Original files remain available.
