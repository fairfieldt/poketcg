First changes

  1. Cache the duel felt rows at the display resolution. Its current inner loop executes two integer divisions per pixel. Those stalls alone cost about 43 ms at 320×240 and 97 ms at 480×360. Keep the completed UI canvas and presentation fence.
  2. Benchmark a packed 3D backend on one populated room. Existing GL display lists already cache commands. The RSP still processes thousands of triangles each frame.
  3. Use character LOD and conservative visibility rejection. Keep detailed lead faces for conversations and naming. Halving all actor triangles, including the player, removes about 42% of submitted geometry in the lab and Lightning Club.
  4. Split the overworld into coarse visible chunks. Its 5,511 static triangles dominate the cost. Character LOD alone cannot solve the island.

The division calculation uses the NEC VR4300 manual, Table 3-12 and Nintendo's CPU clock specification.
